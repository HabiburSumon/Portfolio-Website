# Habibur Sumon - Portfolio Website

A professional personal portfolio website for **Habibur Sumon**, Software Engineer at Unisoft System Limited.

## Pages

- **Home** (`index.html`) - Hero section with name, title, tagline, and CTAs
- **About** (`about.html`) - Bio, work experience, education, and skills
- **Projects** (`projects.html`) - Case studies including SwiftPay and Push Notification System
- **Resume** (`resume.html`) - Professional summary, experience, education, and skills
- **Contact** (`contact.html`) - Contact form and social links

## Design

- **Style:** Minimalist with clean typography and generous whitespace
- **Font:** Inter (Google Fonts)
- **Colors:** White background, charcoal text, blue accent (#007ACC)
- **Responsive:** Mobile-first breakpoints at 320px, 768px, 1024px

## Features

- Responsive navigation with mobile hamburger menu
- Smooth scroll animations using IntersectionObserver
- Animated skill bars
- Contact form with client-side validation
- SEO meta tags on all pages
- WCAG AA accessibility (semantic HTML, alt text, focus indicators, contrast)
- Reduced motion support for accessibility

## Deployment

This is a static site. Deploy to any static hosting service:

- **GitHub Pages:** Push to a repo and enable Pages
- **Netlify:** Drag-and-drop the folder or connect to Git
- **Vercel:** Import the project

## Customization

1. Replace the profile placeholder with an actual photo
2. Update contact email and social links in all HTML files
3. Update project details and add more projects
4. Connect the contact form to a service like Formspree
5. Update the domain in `robots.txt` and `sitemap.xml`
